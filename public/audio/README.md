# Ambient Audio

Drop a royalty-free mp3 here named `theme.mp3` (i.e. `public/audio/theme.mp3`)
and it will automatically be picked up by the "Ambient" toggle in the
dashboard header — no code changes needed.

Suggested legal, free-for-commercial-use sources:
- Pixabay Music — https://pixabay.com/music/ (no attribution required)
- YouTube Audio Library — https://studio.youtube.com (free Google account required)
- Free Music Archive — https://freemusicarchive.org (filter by CC license)

Look for tags like "tactical," "military," "dramatic trailer," "espionage,"
or "cinematic tension" for a tone that fits the dashboard.

The toggle is off by default and only starts playing when a user clicks it,
in line with browser autoplay policies and to avoid unsolicited audio.
